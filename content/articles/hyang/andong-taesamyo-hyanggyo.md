> *편집실 안내 — 《영가회 40년사》 444~445쪽에 실린 문화재 안내를 옮겼습니다.*

## 안동 태사묘

| 항목 | 내용 |
|---|---|
| 위치 | 태사길1길 24-1 (북문동, 구 시청 옆). 안동역에서 5분 거리 |
| 지정 | 지방기념물 제15호 |
| 봉안 | 고려 개국공신 **김선평 · 권행 · 장정필** 삼태사의 위패 |
| 이건 | **1540년(중종 35년)** 김광철 부사가 현 위치로 옮김 |
| 유물 | **삼공신유물 보물 제451호** — 삼태사의 유물, 옥관자 외 21점 보존 |
| 향사 | 2월 · 8월 **중정일(中丁日)** |
| 관리 | 안동태사묘 관리위원회 |

삼태사는 930년 고창(古昌) 전투에서 고려 태조 왕건을 도와 견훤군을 물리친 세 사람으로, 여기에서 〈안동〉이라는 이름이 나왔습니다.

## 안동향교

| 항목 | 내용 |
|---|---|
| 위치 | 향교길 65 (송천동) |
| 대성전 | 성균관 대성전과 **동일한 규모**였습니다 |
| 봉안 | **오성(五聖) · 송조사현(宋朝四賢) · 동국십현(東國十賢) 등 27위** |
| 석전대제 | 2월 · 8월 **상정일(上丁日)** |
| 연혁 | 6·25 전란 때 소실되고 **1986년** 현 위치에 중건 |
| 가는 길 | 시내에서 8km (안동시청 → 용상 → 송천동) |

## 예안향교

| 항목 | 내용 |
|---|---|
| 위치 | 도산면 퇴계로 2020-13 |
| 지정 | 도 유형문화재 제28호 |
| 연혁 | 조선 초기 창건, **선조 34년(1601년) 중수**, **영조 21년(1745년)** 크게 개수 |
| 봉향 | **공자(孔子) 등 한국과 중국의 성현** |
| 석전대제 | 2월 · 8월 **상정일(上丁日)** |
| 가는 길 | 시내에서 20km (안동시청 → 와룡 → 예안향교) |
