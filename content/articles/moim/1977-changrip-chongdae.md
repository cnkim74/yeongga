## 창립총회 개요

| 항목 | 내용 |
| --- | --- |
| 일시 | 1977년 3월 26일 18:00 |
| 장소 | 종로구 견지동 **덕수빌딩 지하 1층 연회장** |
| 참석 | 61명 |
| 이름 | **영가상록회(永嘉常綠會)** — 뒤에 영가회로 줄여 부름 |
| 회장 | **김해길** (안동농림 출신) |
| 총무 | **권화섭** |

## 창립총회에서 정한 것

- **회칙** — 상정한 원안 그대로 통과
- **임원** — 준비 모임에서 정한 안건을 모두 통과
- **회비** — 초창기에는 회비를 두지 않고 자발적인 기부금으로 운영
- **사무실** — 당분간 **장원석** 회원 소유의 덕수빌딩 사무실을 무료로 사용
- **회장 자격** — 정치인은 회장에서 배제
- **신입회원** — 기존 회원 3인 이상의 추천을 받아 회장단 심의 후 결정

## 창립까지의 준비 모임

창립총회에 앞서 1976년 여름부터 네 차례 준비 모임을 가졌습니다.

| 일시 | 장소 | 내용 |
| --- | --- | --- |
| 1976.8.12 | 한정식 **용수산** | 재경 안동 3개 학교 출신 모임을 만들자는 제안이 나옴 |
| 1976.9.14 | 한정식 **남강** (조계사 뒤) | 모임 구성 논의. 회칙 초안은 이상두가 맡기로 함 |
| 1976.11.17 | 한정식 **남강** (인사동) | 회칙(안) 심의·확정, 회장 선출 방식 합의 |
| 1977.1.18 | 한정식 **남강** | 창립총회 날짜와 장소를 덕수빌딩 지하홀로 결정 |

회칙 초안은 **이상두**와 **권화섭**이 작성했습니다.

## 회장 선출 방식

- 안동의 3개 학교(**안동농림 · 안동사범 · 안동중고등학교**) 설립 연도순으로 회장을 맡기로 함
- 임기는 2년, 연임 가능
- 정치인은 제외하고, 회원 누구나 잘 알고 거부감이 없는 사람으로 정함

이 순서에 따라 초대 회장은 안동농림 출신인 김해길이 맡았습니다.
