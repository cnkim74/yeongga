## 회장이 바뀐 총회

2025년 2월 7일 열린 정기총회는 **회장 이·취임**이 함께 이뤄진 자리였습니다. 총회 안건으로 신임 회장과 감사를 선임하고, 제2부에서 현 회장의 이임 인사와 신임 회장의 취임 인사가 이어졌습니다.

## 회순

| 부 | 순서 |
|---|---|
| 제1부 · 정기총회 | 개회 및 국민의례 · 주요 참석자 소개 · 회장 인사 · 축사 |
| | **영가문화상 및 선행상 시상** |
| | 안건 — 2024년 사업실적 보고 |
| | 안건 — 2024년 결산 및 감사의 감사 보고 |
| | 안건 — **신임 회장 및 감사 선임** |
| | 안건 — 2025년 사업계획 보고 |
| 제2부 | 현 회장 이임 인사 · 신임 회장 취임 인사 · 특강 |
| 제3부 | 건배 제의 · 만찬 |

## 영가문화상과 선행상

회의 오랜 전통인 **영가문화상**과 **선행상** 시상이 총회 자리에서 이뤄졌습니다. 고향과 회를 위해 공헌한 이들을 회원들 앞에서 기리는 순서입니다.

## 특강 — 100세 시대의 건강

> **이용태** 박약회 회장

## 편집실의 정리

- 제9대 회장기가 시작된 자리
- 시상·결산·선임·특강이 한자리에서 이뤄진, 회의 한 해를 여는 총회
