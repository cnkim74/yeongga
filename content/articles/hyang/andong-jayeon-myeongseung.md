> *편집실 안내 — 《영가회 40년사》 446~448쪽에 실린 안내를 옮겼습니다.*

## 영호루

| 항목 | 내용 |
|---|---|
| 위치 | 정하동 |
| 유래 | 공민왕이 홍건적의 난을 피하여 안동으로 몽진하였을 때 이곳에서 유람을 하였다고 함 |
| 현판 | **공민왕 친필** |
| 위상 | **영남 3대루**의 하나 |

지면에는 남한 4대 누각으로 **촉석루(진주) · 영남루(밀양) · 광한루 · 영호루**가 적혀 있습니다.

## 용계 은행나무

| 항목 | 내용 |
|---|---|
| 위치 | 길안면 용계리 743 외 |
| 지정 | **천연기념물 제175호** |
| 유래 | 조선 선조 때 훈련대장인 **송암** 선생이 **은행계를 조직하고 주변에 대를 쌓아 보호** |
| 크기 | 높이 **37m**, 뿌리 부분 둘레 **16m**, 가슴 높이 둘레 **14.5m** — 어른 14명이 띠를 둘러야 함 |
| 수령 | **700년 추정** — 우리나라 최대의 거목 |
| 보존 | 임하댐 건설로 수몰 위기에 처하자 그 자리에서 **15m 들어올리는 상식(上植) 공사**(1990.11~1993.7) |
| 가는 길 | 시내에서 31km |

## 안동댐

| 항목 | 내용 |
|---|---|
| 위치 | 성곡동 |
| 성격 | 4대강 유역 종합개발계획에 따른 **다목적댐** |
| 주변 | 물문화관, 민속촌, 드라마 촬영장, **월영교** 등 주변 경관이 좋음 |
| 가는 길 | 시내에서 6km (안동시청 → 법흥지하도) |

## 임하댐

| 항목 | 내용 |
|---|---|
| 위치 | 임하면 임하리 |
| 성격 | 4대강 유역 종합개발계획에 따른 **다목적댐** |
| 주변 | 백운정, 호계서원, 홍보관 등 가족 단위 놀이마당으로 좋음 |
| 가는 길 | 시내에서 17km (안동시청 → 용상동 → 임하) |

## 암산 유원지

| 항목 | 내용 |
|---|---|
| 위치 | 남후면 광음리 |
| 지정 | **구리측백나무 자생지 천연기념물 제252호** |
| 이용 | 여름에는 보트장, 겨울에는 천혜의 스케이트장 |
| 행사 | 매년 1월 **안동암산얼음축제**와 **장빙제** |
| 가는 길 | 시내에서 11km |

## 무릉 유원지

| 항목 | 내용 |
|---|---|
| 위치 | 남후면 무릉리 137-2 |
| 특징 | 수려한 경관의 절벽을 이루고 있으며 보트를 이용할 수 있음 |
| 가는 길 | 시내에서 9km |

## 도산온천

| 항목 | 내용 |
|---|---|
| 위치 | 도산면 온천로 570 |
| 수질 | 지하 **580m**에서 토출. 약알칼리성에 **중탄산나트륨** 함유 |
| 효용 | 모세혈관 확장, 혈압 강화, 심장 부담 감소 및 피부질환 |
| 가는 길 | 시내에서 28km |

## 지례예술촌

| 항목 | 내용 |
|---|---|
| 위치 | 임동면 지례예술촌길 390 |
| 구성 | 종택인 지촌종택, 지촌제청, 지산서당을 이건해 조성 |
| 활용 | 예술인의 창작 활동장, 전통생활 학습장, 유교연수원 등 |
| 가는 길 | 시내에서 30km |
