## 신년회와 함께 연 제49차 정기총회

2026년 1월 7일 수요일, 국방컨벤션에서 **2026 신년회 및 제49차 정기총회**가 열렸습니다.

## 회순

| 부 | 순서 |
|---|---|
| 제1부 · 신년인사회 | 개회 및 국민의례 |
| | 회장 인사 및 참석자 소개 |
| | 원로회의 의장 축사 |
| | **유공자 표창** |
| 제2부 · 정기총회 | 안건 Ⅰ — 2025 주요 사업결과 보고 |
| | 안건 Ⅱ — 2025 예산 집행 및 회무 감사 |
| | 안건 Ⅲ — 2026 사업계획 |
| 제3부 · 만찬 | 뷔페 만찬 · 명사강연 · 작은 음악회 |

## 명사강연 — 고령사회와 신탁의 역할

회원 다수가 맞이한 고령사회를 주제로, 자산 승계와 신탁 제도를 짚는 강연이 만찬과 함께 이어졌습니다. 작은 음악회는 포드림 공연단이 맡았습니다.

## 2026년 사업계획의 뼈대

| 구분 | 내용 |
|---|---|
| 회의 | 정기총회(1월) · 운영협의회 · 이사회 (연중) |
| 회원 친목 | 해외 문화탐방 · 국내 문화탐방 |
| 원로 | 7차 원로회원 간담회 · 하반기 원로회의 간담회 |
| 고향발전 | 안동발전 영가포럼 (국회) |

## 편집실의 정리

- **제49차** — 반세기를 눈앞에 둔 총회
- 신년인사·총회·만찬을 3부로 나눠 치르는 형식이 자리 잡은 모습
