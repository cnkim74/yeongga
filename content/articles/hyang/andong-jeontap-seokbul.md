## 안동 법흥사지 칠층전탑 — 국보 제16호

'신세동 칠층전탑'에서 이름이 바뀌었습니다.

| 항목 | 내용 |
|---|---|
| 위치 | 법흥동 8-1 |
| 지정 | 국보 제16호 |
| 시대 | 통일신라시대 8세기경 건립 |
| 규모 | 높이 **17m**, 기단폭 **7.5m** |
| 특징 | 국내에서 가장 크고 오래된 전탑(벽돌탑). 팔부중상(八部衆像) · 사천왕상(四天王像) · 12지신을 판석으로 축조 |
| 가는 길 | 시내에서 3.2km |

## 안동 운흥동 오층전탑 — 보물 제56호

| 항목 | 내용 |
|---|---|
| 위치 | 운흥동 231 (안동역 보선사무소 내) |
| 지정 | 보물 제56호 |
| 시대 | 통일신라시대 |
| 규모 | 높이 **8.35m**, 기단폭 **3.65m** |
| 특징 | 《영가지》에 나오는 **법림사 터**로 추정. 1969년 복원 |

## 조탑동 오층전탑 — 보물 제57호

| 항목 | 내용 |
|---|---|
| 위치 | 일직면 조탑리 139 |
| 지정 | 보물 제57호 |
| 시대 | 통일신라시대 제작 추정 |
| 규모 | 높이 **8.65m**, 기단 너비 **7m** |
| 특징 | 양각한 조형미가 뛰어나 사진작가의 촬영 대상이 된다 |
| 가는 길 | 시내에서 18km (안동시청 → 무릉 → 남안동IC 입구) |

## 안동 이천동 마애여래입상 — 보물 제115호

| 항목 | 내용 |
|---|---|
| 위치 | 이천동 (연미사) |
| 지정 | 보물 제115호 |
| 규모 | 높이 **9.95m**, 머리 부분 **2.43m**, 너비 **7.20m** (자연석 화강암 석벽) |
| 가는 길 | 시내에서 6km (안동시청 → 북후 방면) |
| 그 밖에 | 2010년 **제비원 솔씨공원**이 준공되면서 성주의 본향 〈성주풀이〉가 부각됐다 |
