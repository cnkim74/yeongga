> *편집실 안내 — 《영가회보》 8-5호(2023년 1월 15일 발행) 7면 박스를 지면 그대로 옮겼습니다.*

## 〈안동출신〉

- 감사원 = 이영웅 감사연구원장
- 국무조정실 = 이동혁 조세심판원 상임심판관
- 기획재정부 = 김태곤 예산총괄과장(부이사관)
- 과학기술정보통신부 = 강도현 정보통신정책실장, 류광준 기획조정실장
- 외교부 = 김의환 뉴욕총영사관 총영사, 강부성 駐다낭 총영사
- 농림축산식품부 = 김기훈 국립종자원장
- 환경부 = 금한승 기후탄소정책실장
- 보건복지부 = 이창준 보건의료정책관
- 고용노동부 = 류경희 산업안전보건본부장, 권태성 직업능력정책국장
- 해양수산부 = 이시원 감사관
- 경찰청 = 송병일 경찰인재개발원장, 김병우 국가수사본부 수사기획조정관
- 서울특별시 = 김의승 행정1부시장

## 〈예천출신〉

- 문화체육관광부 = 전병극 제1차관
- 노동부 = 권기섭 차관
- 대통령실 = 안병윤 홍보소통수석실 선임행정관
- 서울행정법원 = 장낙원 법원장
- 한국지방세연구원 = 강성조 원장
- 서울시 = 정상훈 행정국장
- 경찰청 = 이영상 인천광역시경찰청장
- 국립서울현충원 = 김수삼 원장
